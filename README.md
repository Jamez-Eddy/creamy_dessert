# Creamy_Dessert — Luxury Cake Website

A premium, responsive website for Creamy_Dessert.

## Included
- Luxury editorial landing page
- Responsive desktop/tablet/mobile layout
- Cake collection with filters
- Birthday, wedding and signature cake cards
- CEO/founder section using both supplied images
- Custom order enquiry modal
- Animated marquee, hover effects and cursor glow
- About/process/experience sections
- Ready for WhatsApp, email or backend order integration

## Run
Open `index.html` in a browser, or run:

    python3 -m http.server 8000

Then open:

    http://localhost:8000

## Launch checklist
1. Replace the placeholder WhatsApp number and email.
2. Replace sample cake image URLs with Creamy_Dessert's own product photography.
3. Connect the enquiry form to WhatsApp, email, Formspree, or a backend.
4. Add Instagram/TikTok/Facebook URLs.
